## 🔧 Troubleshooting Common Issues

### "Windows protected your PC" Warning
This happens because DesignHub is new and not widely known yet. Click **"More info"** → **"Run anyway"**. This is safe since the software is open source and reviewed by the community.

### DesignHub Won't Open After Download
- Make sure you have at least 500 MB of free disk space.
- Try right-clicking the file and selecting **"Run as administrator"**.
- Check that your Windows is updated to version 10 or later.

### Fonts or Icons Not Loading
- If you have internet, go to **Settings** → **Update Library** to download new content.
- Restart the application after updating.

### Where Are My Exported Files?
By default, DesignHub saves exports to a folder called **"DesignHub Exports"** in your **Documents** folder. You can change this location in Settings.
